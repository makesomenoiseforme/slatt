# Slat: общие функциональные правила

Версия 0.1, 19.10.2026. Дополнение к [функциональной карте](functionality.md). **С** — согласованный принцип; **П** — предлагаемое правило; **О** — открытый вопрос. Здесь описано поведение продукта, а не структура БД или API.

## 1. Различаемые понятия

| Понятие | Значение для продукта |
|---|---|
| Аккаунт | Подтверждённый способ входа человека; может содержать разные роли |
| Рабочая карточка ученика | Запись преподавателя, которая может существовать до регистрации семьи |
| Учебная связь | Работа конкретного преподавателя с учеником по конкретному предмету/условиям; у одного ученика отдельные предметные карточки без дублирования личности |
| Семейная связь | Подтверждённое отношение взрослого к ребёнку с определёнными полномочиями |
| Доступный слот | Время, разрешённое преподавателем для запроса занятия |
| Запрос записи | Предложение ученика/родителя, ещё не подтверждённое занятие |
| Занятие | Конкретная встреча; может быть частью серии и включать группу |
| Посещение | Участие конкретного ученика в конкретном занятии |
| Начисление | Основание суммы за услугу/пропуск по договорённости; не факт поступления денег |
| Оплата | Поступление/возврат денег и его подтверждение |
| Задание | Выданное требование с материалом, адресатами и возможным сроком |
| Попытка | Конкретная версия ответа ученика |
| Личная заметка | Рабочая запись преподавателя; не опубликованный итог |
| Учебный итог | Отдельно опубликованная информация для ученика/семьи |

Основные различия следуют из принятых решений. Точная детализация объектов и связей — П; техническая модель не выбрана.

## 2. Права и видимость

Ниже — предлагаемая матрица, ограниченная согласованными границами. Доступ всегда относится к конкретной связи; наличие роли в аккаунте не даёт доступа ко всем данным человека.

| Данные/действие | Преподаватель | Ученик | Связанный родитель |
|---|---|---|---|
| Свои занятия | Управляет | Просматривает | Просматривает занятия ребёнка |
| Разрешённые слоты преподавателя | Настраивает | Запрашивает запись | Запрашивает запись |
| Подтверждение запроса | Подтверждает/отклоняет | Видит результат | Видит результат для ребёнка |
| Чужие занятые интервалы | Свой календарь | Только отсутствие доступного слота | Только отсутствие доступного слота |
| Подтверждение проведения | Отмечает | П: видит итоговый статус | П: видит итоговый статус |
| Личная заметка преподавателя | Создаёт/читает | Нет | Нет |
| Опубликованный учебный итог | Готовит/публикует | П: свой итог | Согласованный итог ребёнка |
| Попытка ученика и комментарии | Проверяет свои задания | Свои работы | По умолчанию только согласованная сводка; подробный доступ — О |
| Личный диалог ученик–преподаватель | Этот преподаватель | Этот ученик | Нет |
| Личный диалог родитель–преподаватель | Этот преподаватель | П: нет | Этот родитель |
| Суммы, остатки, задолженность | По своей практике | Только если сам оплачивает данную связь | В пределах подтверждённого семейного доступа |
| Оплата и её подтверждение | П: подтверждает внешнее поступление | П: действие только при роли плательщика | П: по финансовым полномочиям |
| Работа другого преподавателя | Нет | Своя разрешённая история | Разрешённая информация ребёнка |
| Личная библиотека целиком | Своя | Нет | Нет |
| Материал, выданный ученику | Управляет доступом | По назначению | О: не автоматически вместе со сводкой |

**С:** финансовый раздел неплательщика скрыт. **П:** суммы также исключаются из его уведомлений, предпросмотра сообщений и общих сводок. Ученик, оплачивающий одного преподавателя, не получает автоматически доступ к расчётам с остальными.

**С:** базовый просмотр родителя без обязательной регистрации. **П:** ограниченная отзываемая ссылка не даёт автоматически права подтверждать цену, писать от имени родителя или платить. Для расширенных действий подтверждается право доступа; способ ещё открыт. Отозванная ссылка не открывает данные, даже если была сохранена.

## 3. Подключение и объединение профилей

**С:** преподаватель может работать до регистрации семьи. **П:** карточка явно показывает, кто подключён. Отсутствие аккаунта не изображается как отказ ученика от работы или подтверждение родителя.

**П:** приглашение привязано к конкретной связи и ожидаемому действию. При входе существующего пользователя предлагается присоединить эту связь, а не завести вторую историю. Ученик/взрослый подтверждает соответствие приглашения; чужая карточка не раскрывается до проверки доступа.

**О:** кто подтверждает родителя и как разбираются дубли. Совпадение фамилии, телефона семьи или имени ребёнка само по себе не основание объединять истории. Добавление второго преподавателя не раскрывает ему прошлые материалы и переписки автоматически.

## 4. Жизненный цикл записи и занятия

Предлагаемые состояния, если не указано С. Согласованные правила: длительность выбирается из разрешённых преподавателем для ученика вариантов; запрос записи удерживает слот до ответа максимум на 24 часа, затем слот освобождается. Ученик и родитель могут запросить перенос, преподаватель подтверждает; исходное занятие сохраняется до подтверждения. Срок ожидания переноса и случай начала урока раньше истечения резерва ещё открыты.

| Объект | Состояния | Что не следует автоматически |
|---|---|---|
| Запрос | Ожидает ответа → подтверждён / отклонён / истёк; отзыв — П | Подтверждение запроса не подтверждает оплату или проведение |
| Занятие | Запланировано → требует отметки → проведено / пропущено; отмена — П | Истечение времени не означает проведено или пропущено |
| Посещение в группе | Ожидает отметки → присутствовал / отсутствовал; другие варианты — О | Отсутствие одного участника не отменяет урок всей группы |
| Перенос | Предложен → принят / отклонён / отозван | Новый запрос не удаляет исходное занятие |

**С:** подтверждает проведение преподаватель. **П:** «требует отметки» — рабочее состояние очереди, а не новая обязанность семьи. Преподаватель может позднее исправить ошибку; исходное значение и автор изменения сохраняются.

**С:** перенос меняет время существующего занятия и перемещает его в календаре с сохранением истории. Отмена означает отмену встречи заранее; пропуск означает, что запланированная встреча не состоялась. Подтверждение переноса и работа с серией ещё требуют детализации.

**С:** ученик и родитель могут отменять занятие самостоятельно; последствия по действующим условиям показываются до окончательного подтверждения. **П:** предварительный экран содержит отменяемое занятие, применённое правило, денежное начисление для участника с финансовым доступом и изменение остатка пакета. При изменении условий/расчёта до подтверждения показывается актуальный результат. Повторное нажатие не создаёт повторного списания.

**С:** ученик-неплательщик не видит финансовый раздел и суммы. Отмену без финансовых последствий подтверждает самостоятельно; отмену со списанием запрашивает, а плательщик подтверждает после просмотра последствий. Родитель с соответствующими полномочиями либо самостоятельно оплачивающий ученик видит сумму и подтверждает отмену сам. Согласие плательщика не оформляется от имени ученика. **О:** срок ответа, изменение расчёта при ожидании и судьба исходного занятия до подтверждения. **П:** для группы отменяется участие конкретного ученика, без отмены урока для остальных.

**П:** при подтверждении проверять актуальную занятость, включая другой предмет этого преподавателя. Для подтверждённых занятий предлагать предупреждение о конфликте ученика с другой его встречей, не раскрывая сведения о чужом преподавателе. Правила жёсткого запрета/исключения пока О.

**С:** повторяющиеся занятия задаются днями недели, временем, датой начала и необязательной датой окончания. Изменение применяется «только к этому занятию» либо «к этому и последующим»; прошлые занятия сохраняются. **О:** исключения и конфликты серии, буферы, доступные длительности и внешние конфликты; состав разрешённых длительностей определяет преподаватель.

## 5. Проведение и расчёты

**С:** преподаватель выбирает расчёт за отдельные занятия, предоплаченный пакет занятий/часов либо фиксированную оплату за период. Остатки ведутся раздельно по предметам, доступен общий обзор у этого преподавателя. Автоматического переноса денег между предметами нет. Напоминания об оплате автоматически отправляются плательщику по настройке преподавателя; ученик-неплательщик их не получает. Конкретные параметры схем, частота напоминаний и финансовые последствия паузы ещё открыты.

**С:** пропуск — отдельный статус; финансовое последствие определяется правилом, заранее установленным преподавателем. **О:** область действия, варианты суммы/списания, сроки отмены и ручные исключения. **П:** до настройки правила Slat не делает скрытого начисления за пропуск и не обещает бесплатный пропуск как условие договора. Система показывает, что финансовый вопрос требует решения. Изменение правила не должно молча пересчитывать прошлые занятия; точное версионирование ещё проектируется.

**П:** оплаченный пакет не означает, что все уроки состоялись. Внешнюю оплату подтверждает преподаватель; сообщение плательщика, если такой сценарий будет выбран, не равно поступлению. Для внутреннего платежа успешность определяется подтверждением платёжной операции, а не возвращением пользователя на экран Slat.

**П:** исправление статуса урока показывает затрагиваемые начисления; возврат денег требует отдельной операции. Денежный остаток и количество оставшихся занятий различаются, особенно при разной цене/длительности. Не смешивать плановую выручку и полученные деньги.

**С:** частичная оплата учитывает внесённую сумму, остаток остаётся задолженностью; срок просрочки определяется отдельно. Пакет имеет ограниченное количество занятий/часов и необязательный срок. Бессрочный остаток не сгорает по времени; установленный срок показывается семье заранее. **О:** что происходит с остатком после истечения срока, частично оплаченные пакеты, распределение, возвраты и расчёт фиксированного периода.

**С:** новая цена действует с выбранной даты для новых договорённостей, плательщик уведомляется заранее. Прошлые начисления/долги и купленные пакеты не пересчитываются. Для уже согласованных будущих занятий предлагается изменение условий с даты с одним подтверждением семьи для затронутых занятий; до подтверждения действует согласованная цена. **О:** полномочия подтверждающего, отсутствие подключённой семьи и конкретный процесс. **П:** показ затрагиваемых занятий и суммы до подтверждения; пересчёт не запускается простым редактированием справочной цены.

## 6. Задание, попытки и обратная связь

**С:** у занятия может быть несколько отдельных домашних работ со своими заданиями и состоянием проверки. Срок сдачи каждой работы необязателен. Работа без срока остаётся текущей; просрочка к ней не применяется. **П:** отсутствие срока не скрывает работу из списка текущих и не препятствует сдаче.

**П:** состояния назначения «черновик / выдано / закрыто» отделены от состояния работы конкретного ученика «не сдано / сдано / проверено / нужно исправить». Просрочка — отдельный признак относительно срока, а не замена состояния.

**С:** можно сдавать целиком или по заданиям. **П:** частичная сдача явно показывает охват: сданная часть не обозначает всю работу завершённой. Черновик не появляется как готовая сдача. Непринятый из-за ошибки загрузки файл не отображается как успешно отправленный.

**С:** история попыток поддержана. **П:** исправление создаёт новую версию; прежний комментарий остаётся у прежней попытки. Ученик видит, какую версию сейчас проверяют. Общий шаблон и выданная копия различаются; изменение шаблона не переписывает выполненные задания.

**С:** режим повторных попыток задаётся для каждой работы: свободные исправления либо новая попытка по разрешению преподавателя; по умолчанию свободные исправления. Изменение условий уже начатого задания сохраняет исходную версию и попытки; ученик видит, что изменилось. Требование нового ответа касается только затронутых вопросов. **О:** закрытие работы, ограничения попыток и обработка прежних оценок после изменения условий. **П:** прежняя проверка не переносится на существенно изменённый вопрос как будто условия остались прежними.

**С:** короткие ответы проверяются автоматически, развёрнутые — преподавателем с возможным кратким AI-комментарием. Показ результата автопроверки настраивается преподавателем для каждой работы: сразу после сдачи либо отложенно после проверки; по умолчанию сразу. Раскрытие готового правильного ответа настраивается отдельно; по умолчанию он скрыт, доступны «верно/неверно» и комментарий в выбранный момент публикации. **О:** допустимые формы/единицы ответа и подробный порядок отложенной публикации. **П:** при неопределённой проверке — «нужна проверка», а не уверенное «неверно». Отложенный режим не должен раскрывать скрытый результат через уведомления или сводку.

**С:** оценка необязательна: достаточно статуса проверки и обратной связи; баллы/критерии добавляются преподавателем при необходимости. Выполнение и результат можно отметить после проверки вне Slat, с явным источником «проверено преподавателем вне сервиса». При этом не создаются вымышленные файлы, попытки или факт цифровой сдачи от имени ученика. **П:** источник сохраняется при использовании результата в учебной сводке; ручная проверка не запускает автопроверку отсутствующего ответа.

## 7. Заметки, сводки, текущий контекст и AI

**С:** заметка «Как прошло занятие?» личная и необязательная. Учебный итог для семьи публикуется отдельно. **П:** перенос фрагмента заметки в итог требует предварительного просмотра; личные сообщения не прикрепляются как источники, доступные семье.

**С:** черновик сводки за период готовится вручную по запросу либо по настроенному расписанию; публикация в обоих случаях только после подтверждения преподавателем. Ученик и родитель получают общее опубликованное учебное содержание: что изучали, что получается самостоятельно, трудности, следующий шаг и необходимость участия родителя. Финансовых сведений в нём нет, личные вопросы остаются в отдельных разговорах. Основания — конкретные работы/наблюдения при их наличии; выдуманный единый процент знаний не создаётся. **П/О:** показывать разрешённый фрагмент или доступный источник, не открывая автоматически все попытки, личные заметки и переписки.

**С:** AI от имени преподавателя не публикует и не изменяет данные без его подтверждения. **П:** вывод показывает дату и доступный адресату источник; при недостатке данных это обозначается явно. Нет оснований делать вывод «тема освоена» только из посещений, сроков или количества выполнений.

**С:** помощь ученику начинается после попытки или конкретного сообщения о трудности. **П:** ответ различает AI и преподавателя; сбой AI не мешает сдать работу и задать вопрос человеку. Черновик AI не считается проверенным наблюдением.

**С:** преподаватель определяет доступность ученических AI-подсказок отдельно для каждой работы. При отключённых подсказках вопрос преподавателю остаётся доступен. Это не выключает автоматически AI-инструменты самого преподавателя. Значение по умолчанию для подсказок и изменение режима в уже начатой работе ещё требуют решения.

**О:** параметры Learning Memory и разрешённые внешнему AI данные. Наличие функции в карте не является разрешением отправлять реальные данные ребёнка внешнему сервису.

## 8. Договорённости, архив и доступ

**С:** учебная цель необязательна, её можно добавить позже, не блокируя занятия и задания. Каждая предметная карточка может иметь собственную цель.

**С:** пауза сохраняет учебную связь и историю. Новые повторяющиеся занятия на период паузы не назначаются; существующие встречи показываются для отдельного решения, а не молча отменяются. Пауза одной предметной карточки не останавливает другие предметы или преподавателей. **О:** возвращение из паузы, финансовые последствия и поведение индивидуального участия в группе.

**П:** цель, цена и регулярное время могут иметь разные правила подтверждения. В истории различаются «установил преподаватель», «подтвердил ученик», «подтвердил родитель», «преподаватель зафиксировал внешнюю договорённость». Последнее не изображается нажатием от лица семьи. **О:** полномочия и необходимость подтверждений для каждого вида изменения.

**С:** завершение занятий сохраняет собственные работы и расчёты. **П:** прекращение связи останавливает новые назначения, но будущие встречи/неоплаченные операции разбираются явно. Восстановление связи не повторяет старые начисления.

**О:** дальнейший доступ к файлам преподавателя, длительность хранения и экспорт. Архивирование и прекращение доступа — не удаление персональных данных; обработка удаления требует отдельного сценария и не считается решённой сохранением истории.

## 9. Библиотека и общая база

**С:** личная библиотека организуется папками и тегами. Материал из общей базы сохраняется для адаптации в личной копии, если условия использования допускают это. Изменение копии не меняет оригинал и ранее выданные работы. Версии уже выданного задания обновляются только отдельным действием с сохранением ответов и уведомлением об изменениях.

**С:** преподаватель предлагает материал в общую базу, публикация возможна только после модерации содержания, источника и прав использования. До одобрения материал остаётся личным и не появляется в общем доступе. **П:** модератор получает доступ к отправленной версии, а не ко всей библиотеке; сохраняются авторство и происхождение. **О:** конкретные правила прав/адаптации, полномочия модераторов, исправления опубликованного материала и обновление личных копий.
